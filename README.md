# DSA-Practice (Java)

Personal practice repository for Data Structures & Algorithms, built while learning Java and preparing for technical interviews (target: FAANG-level roles).

## 📂 Structure

| Folder | Topics Covered |
|---|---|
| `Basics/` | Core Java syntax, math-based logic (factorial, digits, primes, Fibonacci) |
| `Arrays/` | Traversal, searching, max/min, duplicates, in-place manipulation |
| `Arrays2D/` | Matrix input/output, sum, transpose, diagonal, search |
| `Strings/` | Split into `Basics`, `Counting`, `Modification`, `Logic` — palindrome, anagram, compression, etc. |
| `Sorting/` | Bubble, Selection, Insertion Sort |
| `Recursion/` | Recursion fundamentals through backtracking (N-Queens, Sudoku Solver, subsets, permutations) |
| `ArrayList/` | Common `ArrayList` operations |
| `LinkedList/` | Singly linked list ops — reverse, cycle detection, palindrome check |
| `Stack/` | Array-based, LinkedList-based, and JCF-based stacks + problems |
| `Queue/` | Array, LinkedList, Circular, and two-stack queue implementations |
| `OOPS/` | Core OOP concepts — inheritance, abstraction, encapsulation, polymorphism |

## ▶️ How to run any file
```bash
javac FileName.java
java FileName
```

## 🎯 Purpose
This repo tracks my DSA learning progress from fundamentals toward advanced topics (Trees, Graphs, Heaps, DP) as part of long-term interview preparation.

## 📌 Status
Actively maintained — new topics added regularly. Older solutions are periodically revised for cleaner code and edge-case handling.
